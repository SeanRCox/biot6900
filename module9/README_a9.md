In the graded Notebook 3 assignment, I used a synthetic malaria cohort to explore clinical NLP and target leakage. I configured early clinical signals and downstream interventions, extracted concepts from generated notes with assertion handling, trained a model, and used permutation importance and AUROC changes to identify leakage. The cohort and notes are synthetic, so the model results do not represent real-world malaria prediction.

To run the assignment, open `BIOT6900_Module9_Notebook3_Graded.ipynb` and select **Kernel → Restart & Run All**. The notebook requires Python with `pandas` and `scikit-learn`; it does not require external clinical data or services. The graded interpretation prompts are in Part D (D1–D4). No external-data or service dependencies were needed for this assignment.
